ARMA / ARIMA / SARIMA

Famille ARMA à variance constante : innovations gaussiennes ou à queues lourdes, différenciation et facteurs saisonniers optionnels. Erreurs-types de prévision multi-pas via poids MA(∞) exacts. Deux vraisemblances : conditionnelle (défaut) et exacte (Kalman, style EViews / statsmodels).

Démarrage rapide

from makystats import arma, arima, sarima, select_arma_order

res = arma(y, mean="ARMA", ar=1, ma=1, trend="c").fit()

# Aligner EViews ARMA ML / statsmodels ARIMA
res = arma(y, ar=1, ma=1, trend="c", likelihood="exact").fit()
s = res.summary()  # str
print(s)

res = arima(prix, order=(1, 1, 1), trend="c").fit()
res = sarima(ylog, order=(0, 1, 1), seasonal_order=(0, 1, 1, 12),
             trend="n", likelihood="exact").fit()

Paramètres

ParamètreType / défautDescription
ar / p int ou liste, défaut 0 Ordre AR non saisonnier. Entier = retards 1…p ; liste = retards creux (ex. [1, 4]).
ma / q int ou liste, défaut 0 Ordre MA non saisonnier (mêmes règles que AR).
d {0, 1, 2}, défaut 0 Différences régulières (1−L)^d. Les prévisions sont en niveaux par défaut si d>0.
seasonal_order (P, D, Q, s) ou None SARIMA multiplicatif. D est appliqué en amont ; P, Q, s entrent dans le filtre.
trend 'n'|'c'|'t'|'ct', défaut 'c' Déterministes (style statsmodels). Avec likelihood='exact', const est la moyenne inconditionnelle (C d’EViews), pas l’intercept μ(1−φ).
mean str, défaut 'Constant' Structure de moyenne : Constant, Zero, AR/ARMA, ARX/ARMAX, HAR.
likelihood 'conditional'|'exact', défaut 'conditional'
  • conditional (défaut) : MLE conditionnelle + burn-in (moteur type ARMA–GARCH). Échantillon effectif ≈ n − max(p,q). Accepte dist non gaussien.
  • exact : filtre de Kalman stationnaire (gaussien uniquement). Échantillon complet ; aligne EViews ARMA ML et statsmodels ARIMA. Supporte trend ∈ {n,c,t,ct}, exogènes, retards creux et SARMA multiplicatif.
Préférez exact pour un ARMA gaussien comparable à EViews / statsmodels. Gardez conditional pour les innovations non gaussiennes ou la continuité avec GARCH.
dist 'normal'|'t'|'skewt'|'ged', défaut 'normal' Loi des innovations. Seul normal est admis avec likelihood='exact'.
x array / DataFrame, optionnel Régresseurs exogènes (ARX / ARMAX), différenciés comme y si besoin.
cov_type 'opg'|'hessian'|'robust'|'qml', défaut 'opg' Covariance des paramètres. Sous exact : OPG des scores de Kalman.
center, adjust_sample bool Centrage et ajustement d’échantillon (chemin conditionnel).
max_iter, tol int / float Limites de l’optimiseur (BFGS).

Diagnostics du résumé

summary() affiche un bloc style statsmodels sur résidus standardisés : Ljung–Box, Jarque–Bera, hétéroscédasticité (ratio de variances), asymétrie et kurtosis.

Erreurs-types de prévision

Intervalles multi-pas via poids MA(∞) exacts (intégration pour d = 1, 2 en niveaux).

Sélection d’ordres

tab = select_arma_order(y, p_range=range(0, 3), q_range=range(0, 3),
                        criterion="bic", likelihood="exact")
from makystats import fit_from_arma_order_table
second = fit_from_arma_order_table(y, tab, rank=2)
