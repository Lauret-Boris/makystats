ARMA–GARCH

MLE conjoint d’une moyenne linéaire et d’une variance conditionnelle (GARCH, GJR, EGARCH, APARCH, FIGARCH) sous innovations normale, t, skew-t ou GED.

Réglages recommandés

ObjectifRéglages typiquesEffet
MLE non contrainte (défaut) nonneg_var=False, domain_repair=True, n_starts=1 α, β libres. Si l’optimum libre sort hors domaine classique, une relance contrainte peut le remplacer.
Optimum libre strict domain_repair=False, nonneg_var=False Ne remplace jamais la solution libre ; pas de UserWarning de domaine.
Variance contrainte (α, β ≥ 0) nonneg_var=True, optionnel stationary_var=True α, β forcés ≥ 0 ; persistance optionnelle < 1. Proche des solveurs GARCH contraints (ex. arch).
SE robustes cov_type='qml' / 'robust' Sandwich Bollerslev–Wooldridge (QMLE).
Moins dépendant du départ n_starts=4 Plusieurs départs (α, β) ; chacun est poli et réparé ; meilleure LL finale.
Moyenne type statsmodels trend='c'|'ct'|'n', d=, seasonal_order= Déterministes / intégration dans l’esprit ARIMA ; variance = GARCH makystats. 
# Défaut non contraint
res = arma_garch(y, mean="AR", ar=1, ma=1, vol="GARCH").fit()

# Variance contrainte + SE sandwich
res = arma_garch(y, vol="GARCH", nonneg_var=True, stationary_var=True,
                 cov_type="qml").fit()

# Multi-départ
res = arma_garch(y, vol="GARCH", n_starts=4).fit()

Réparation de domaine

Si l’optimum libre sort avec α < 0, β < 0 ou (GJR) α+γ < 0, fit relance une optimisation contrainte (sauf domain_repair=False). Flags : domain_retry, domain_retry_accepted.

Lorsqu’une relance contrainte est acceptée, res.converged est réévalué sur la solution réparée (le polish_delta de la solution libre n’est pas réutilisé), afin de ne pas signaler un échec à tort.

Multi-départ

Avec n_starts>1, chaque départ passe par polissage + réparation de domaine ; le classement se fait sur la LL finale (selection='final_loglik_after_polish_and_repair').

select_order(..., start=None) : grille en 'fast', return_best en 'precise'. Un start= explicite s’applique aux deux.
