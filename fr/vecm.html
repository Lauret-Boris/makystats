VECM / Johansen

Modèle à correction d’erreur vectoriel et tests de cointégration de Johansen (trace / max-eigen), avec p-values et valeurs critiques MHM.

Import

from makystats import VECM, select_coint_rank, JohansenTest, summarize_johansen

Sélection du rang — select_coint_rank

rank_res = select_coint_rank(
    data, k_ar_diff=1, test_case="3", method="trace", signif=0.05
)
print(rank_res.rank)
ParamètreDescription
dataDonnées en niveaux (T × k).
k_ar_diffNombre de différences retardées dans le VECM.
test_case'1'…'5' — cas déterministe du test de Johansen.
method'trace' ou 'maxeig'.
signifNiveau pour la décision séquentielle de rang (défaut 0.05).

Les p-values utilisent les surfaces de réponse MHM (MacKinnon–Haug–Michelis).

Estimation — VECM

mod = VECM(data, k_ar_diff=1, coint_rank=1, det_case="3a")
res = mod.fit()
print(res.summary())
ParamètreDescription
k_ar_diffDifférences retardées.
coint_rankRang de cointégration r.
det_case '1', '2', '3a', '3b', '4a', '4b', '5a', '5b' (constante / tendance dans ou hors la relation de cointégration).

Note : makystats utilise test_case / det_case (pas les chaînes statsmodels det_order / deterministic).
