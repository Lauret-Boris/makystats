Stationarity / unit-root tests

Native unit-root and stationarity tests in makystats.stationarity_test (not estimation models). Inspectable OLS tables, multi-specification compares, and sequential ADF strategy.

Guide: makystats/stationarity_test/README.md

Import

from makystats import (
    adf, adf_sequential,
    kpss, pp, dfgls, za,
    engle_granger, unit_root_summary,
)
# aliases: phillips_perron, zivot_andrews_test, df_gls, ers, kpss_test

Quick examples

print(adf(y, regression="ct").summary())
print(adf(y, regression="ct").ols.summary())

seq = adf_sequential(y)
print(seq.summary())
seq.plot()   # decision tree, active path highlighted

print(kpss(y, regression="c").summary())
print(pp(y, regression="ct", lags="auto").summary())
print(dfgls(y, regression="ct", autolag="MAIC").summary())
print(za(y, regression="ct").summary())

print(unit_root_summary(y))

Main parameters

FunctionKey arguments
adf(y, …) regression = n / c / ct · maxlag · autolag = AIC / BIC / None (lag IC on a common sample)
adf_sequential(y, …) maxlag · autolag · alpha (default 0.05) — lag chosen on Model 3, then path 3→2→1 with Φ tests
kpss(y, …) regression = c / ct · nlags = auto or int
pp(y, …) regression = n / c / ct · lags = auto or int
dfgls(y, …) regression = c / ct · maxlag · autolag = AIC / BIC / MAIC
za(y, …) regression = c / t / ct (break type) · trim (default 0.15) · maxlag · autolag · lag_policy = per_break / global
engle_granger(y, x, …) Cointegration residual ADF; see module README for options

Result objects expose .summary(), and where applicable .ols / .regression.summary() for the underlying ADF-type regression. Sequential ADF: seq.adf_model(3), joint Φ via path objects, seq.plot() for the decision tree.

Helpers: kpss_compare, pp_compare, dfgls_compare, za_compare, adf_joint_test, unit_root_summary.
