ARMA / ARIMA / SARIMA

Constant-variance ARMA family: Gaussian or heavy-tailed innovations, optional differencing and seasonal factors. Multi-step forecast standard errors use exact MA(∞) ψ-weights. Two likelihoods: conditional (default) and exact (Kalman, EViews / statsmodels-style).

Quick start

from makystats import arma, arima, sarima, select_arma_order

# ARMA (stationary series)
res = arma(y, mean="ARMA", ar=1, ma=1, trend="c").fit()

# Match EViews ARMA Maximum Likelihood / statsmodels ARIMA
res = arma(y, ar=1, ma=1, trend="c", likelihood="exact").fit()
s = res.summary()       # returns str; Ljung-Box, JB, H, skew, kurtosis
print(s)

# ARIMA on levels (differencing is internal)
res = arima(prices, order=(1, 1, 1), trend="c").fit()
res.forecast(steps=10)                # levels when d>0
res.forecast(steps=10, levels=False)  # on Δy

# Airline-style SARIMA
res = sarima(ylog, order=(0, 1, 1), seasonal_order=(0, 1, 1, 12),
             trend="n", likelihood="exact").fit()

Parameters

Common to ARMA, arma(), arima(), sarima() (and forwarded by select_arma_order / fit_from_arma_order_table).

ParameterType / defaultDescription
ar / p int or list of int, default 0 Non-seasonal AR order. Integer = lags 1…p; list = sparse lags (e.g. [1, 4]).
ma / q int or list of int, default 0 Non-seasonal MA order (same rules as AR).
d {0, 1, 2}, default 0 Regular differences (1−L)^d applied before estimation. Forecast returns levels by default when d>0.
seasonal_order (P, D, Q, s) or None Multiplicative seasonal ARIMA. D is applied upstream; P, Q, s enter the filter. Dense contiguous orders may use the SARIMAX path under likelihood='conditional'.
trend 'n'|'c'|'t'|'ct', default 'c' Deterministics (statsmodels-style): none, constant, linear trend, or both. With likelihood='exact', const is the unconditional mean (EViews C), not the intercept form μ(1−φ).
mean str, default 'Constant' Mean structure label: Constant, Zero, AR/ARMA, ARX/ARMAX, HAR. With AR/MA lags, Constant is promoted to AR.
likelihood 'conditional'|'exact', default 'conditional'
  • conditional (default): burn-in MLE, same engine as the ARMA–GARCH mean equation. Effective sample loses the first max(p,q) observations. Supports non-Gaussian dist.
  • exact: stationary Kalman filter (Gaussian only). Full sample; matches EViews ARMA ML and statsmodels ARIMA on comparable specs. Supports trend in {n,c,t,ct}, exogenous x, sparse lags, and multiplicative seasonal ARMA.
Prefer exact for pure Gaussian ARMA when comparing to EViews / statsmodels. Keep conditional for non-Gaussian innovations or continuity with GARCH grids.
dist 'normal'|'t'|'skewt'|'ged', default 'normal' Innovation distribution. Only normal is allowed with likelihood='exact'.
x array / DataFrame, optional Exogenous regressors (ARX / ARMAX). Differenced like y when d or D > 0. Supported under both likelihoods.
cov_type 'opg'|'hessian'|'robust'|'qml', default 'opg' Covariance of parameters. exact uses OPG of Kalman observation scores.
center bool, default True Demean during optimisation when compatible with trend (conditional path).
adjust_sample bool, default True Conditional path: adjust the effective sample to the lag structure (burn-in).
max_iter, tol int / float Optimiser limits (BFGS).

# Airline log-passengers ARMA(1,1) + constant
res = arma(ylog, ar=1, ma=1, trend="c", likelihood="exact").fit()
# → LL ≈ 121.70, const ≈ 5.508, AR ≈ 0.963, MA ≈ 0.297 (EViews)

res_c = arma(ylog, ar=1, ma=1, trend="c").fit()  # conditional
# → LL ≈ 123.92 on 143 obs (not comparable 1:1 to EViews n=144)

Summary diagnostics

After fit, summary() prints a statsmodels-style block using standardised residuals (Kalman innovations under exact):

  • Ljung–Box Q(1) and Prob(Q)
  • Jarque–Bera and Prob(JB)
  • Heteroskedasticity H (break-variance ratio) and Prob(H)
  • Skew and kurtosis

Methods: test_serial_correlation, test_normality, test_heteroskedasticity.

Forecast standard errors

Multi-step prediction intervals use the exact MA(∞) ψ-weight formula on the working scale, then integrate for d = 1, 2 when returning levels (replaces σ√h). The SARIMAX path keeps the statsmodels SE.

fc = res.forecast(steps=8, conf_int=0.95)

Order selection

ParameterDescription
p_range, q_rangeCandidate non-seasonal AR/MA orders.
d, seasonal_orderFixed for the whole grid.
criterion'aic', 'bic', or 'hqic'.
likelihood Default 'conditional' uses a fast GARCH(0,0) grid when non-seasonal. 'exact' always runs a manual arma(..., likelihood='exact') grid (full sample, comparable IC).
return_bestIf True, also return a fitted model for the winning order.
 
tab = select_arma_order(y, p_range=range(0, 3), q_range=range(0, 3),
                        criterion="bic", likelihood="exact")
from makystats import fit_from_arma_order_table
second = fit_from_arma_order_table(y, tab, rank=2)  # no re-grid
