Engle–Granger

Residual-based cointegration test for two series (Engle–Granger two-step). Null: no cointegration.

README: stationarity_test/README.md

Import

from makystats import engle_granger

res = engle_granger(y0, y1, trend="c", maxlag=None, autolag="AIC")
print(res.summary())
print(res.extra["coint_coef"])   # stage-1 OLS coefficients
print(res.reject_null(0.05))

Parameters

ParameterTypeDescription
y0array_likeFirst series (left-hand side of the cointegrating regression).
y1array_likeSecond series (right-hand side). Aligned on the trailing common sample.
trend'n'|'nc'|'c'|'ct', default 'c' Deterministics in the cointegrating equation (stage 1): n/nc none; c constant; ct constant + linear trend.
maxlagint or NoneMaximum lag for the residual ADF (stage 2). None → rule of thumb from sample size.
autolag'AIC'|'BIC'|'t-stat'|None, default 'AIC' Residual ADF lag selection. Same meaning as adf. Use maxlag=k, autolag=None for a fixed lag (exact match to statsmodels coint with the same lag).

What is computed

  1. Stage 1 — OLS of y0 on y1 (+ deterministics).
  2. Stage 2 — ADF on residuals with regression='n' (no constant in the residual regression; standard residual-based design).
  3. Inference — MacKinnon (1994, 2010) response surfaces for N=2 (bivariate residual-based cointegration), same tables as statsmodels coint. Finite-sample critical values use nobs - 1 (Stata egranger convention).

Result attributes

AttributeContent
statisticResidual ADF t-statistic
pvalueMacKinnon N=2 approximate p-value (continuous, not truncated at 0.01/0.10)
critical_values1%, 5%, 10% (sample-size dependent for c/ct)
lagsLags chosen for the residual ADF
nobsLength of the cointegrating sample
extra["coint_coef"]Stage-1 coefficients (y1, optional const/trend)
extra["r_squared"]Stage-1 R²
extra["adf_nobs"]Effective residual ADF sample size
reject_null(alpha)True if the test rejects no-cointegration at level alpha

Notes

  • With autolag, lag selection follows the native adf policy (common-sample IC). The lag may therefore differ from statsmodels; the MacKinnon mapping of a given statistic remains identical.
  • For trend='n', 2010 finite-sample critical values are not published for N>1 (returned as NaN); the asymptotic p-value is still available.
  • Near-perfect collinearity triggers a warning; the statistic is set to −∞.
