Sequential ADF

Decision strategy over models with trend (3), constant (2) and none (1), including Dickey–Fuller Φ joint tests (applied flowchart style).

Import

from makystats import adf_sequential

Quick start

seq = adf_sequential(y, maxlag=4, autolag="AIC", alpha=0.05)
print(seq.summary())
print(seq.conclusion, seq.model)   # e.g. I(0) around trend
seq.plot()                         # decision-tree style figure

Parameters

ParameterTypeDescription
yarray_like / SeriesSeries to test.
maxlagint or NoneMaximum lag shared across steps.
autolagstr, default 'AIC'Lag selection criterion on Model 3 first.
alphafloat, default 0.05Significance level for the decision path.

Results

AttributeContent
conclusion, modelFinal decision and selected specification
