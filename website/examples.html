How to run locally

git clone https://github.com/Lauret-Boris/makystats.git
cd makystats
pip install -e ".[plot]"
jupyter notebook exemples/VECM/

Requirements typically include makystats, pandas, matplotlib, and any data files shipped next to the notebook under exemples/VECM/data/.
