DF-GLS (ERS)

Elliott–Rothenberg–Stock GLS-detrended Dickey–Fuller test. Often more powerful than ADF under a trend or intercept alternative.

Import

from makystats import dfgls
# aliases: df_gls, ers ; compare: dfgls_compare

Quick start

res = dfgls(y, regression="ct", maxlag=None, autolag="AIC")
print(res.summary())

Parameters

ParameterTypeDescription
yarray_like / SeriesSeries to test.
maxlagint or NoneMaximum lag for the ADF step on GLS-detrended data.
regressionstr, default 'c''c' GLS demeaning, 'ct' GLS detrending.
autolagstr, default 'AIC''AIC', 'BIC', 'MAIC' (Ng–Perron), etc.
