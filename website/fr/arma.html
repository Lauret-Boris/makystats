ARMA / ARIMA / SARIMA

Modèles de moyenne homoscédastiques (variance constante). Même esprit d’API que arma_garch, sans dynamique GARCH.

Démarrage rapide

from makystats import arma, arima, sarima, select_arma_order

# ARIMA(1,1,1) avec constante
res = arma(y, mean="ARMA", ar=1, ma=1, d=1, trend="c").fit()
print(res.summary())

# ARMA « troué » (lags sparses)
res = arma(y, mean="ARMA", ar=[4], ma=1, d=1, trend="c").fit()

# SARIMA (saisonnalité additive)
res = arma(y, mean="ARMA", ar=0, ma=1, d=1,
           seasonal_order=(1, 1, 1, 12), trend="c").fit()

# Sélection d’ordres
tab = select_arma_order(y, max_ar=3, max_ma=3, d=1, trend="c", ic="bic")

Paramètres principaux

ParamètreDescription
mean"AR", "ARMA", "ARX", "HAR", …
ar, maOrdre entier ou liste de lags (ARMA sparse)
dOrdre de différenciation non saisonnière
seasonal_order(P, D, Q, s)
trend"n" / "c" / "t" / "ct"

Résultats (style statsmodels)

  • params, bse, tvalues, pvalues — Series nommées
  • cov_params(), conf_int()
  • arroots, maroots
  • test_serial_correlation, test_heteroskedasticity, test_normality
  • residuals, fittedvalues, fitted_values_level — index d’origine conservé
  • forecast(steps=…), critères d’information
