ARDL

Modèles AutoRegressive Distributed Lag : ARDL en niveaux, UECM, test de bornes PSS, représentation ECM, coefficients de long terme et prévisions multi-pas.

README : makystats/ardl/README.md · Guide : DOCUMENTATION.md

Import

from makystats import select_ardl_order, fit_from_ardl_order_table

Sélection d’ordres — select_ardl_order

tab, best = select_ardl_order(
    y, x,
    maxlag=4, maxorder=4,
    case=3,
    ic="bic",
    common_sample=True,  # défaut : même échantillon pour tous les candidats
    refit_best=True,
)
ParamètreTypeDescription
ysérieVariable dépendante (niveaux).
xDataFrame / ndarrayRégresseurs exogènes (niveaux).
maxlagint, défaut 4Retard maximal de y.
maxorderint, dict ou liste, défaut 4Retard maximal de chaque colonne de x.
caseint 1–5, défaut 3 Cas déterministe PSS : 1 sans constante/tendance ; 2 constante restreinte ; 3 constante non restreinte ; 4 tendance restreinte ; 5 tendance non restreinte.
ic'aic'|'bic'|'hqic'Critère d’information pour le classement.
common_samplebool, défaut True Si True, tous les candidats sont estimés sur le même échantillon effectif pour des AIC/BIC/HQIC comparables. Si False, chaque ordre utilise son échantillon naturel.
refit_bestbool, défaut TrueRe-estime le meilleur ordre sur son échantillon naturel.
max_modelsint, défaut 5000Plafond de sécurité sur le nombre de modèles.

fit_from_ardl_order_table(tab, rank=1) re-estime une ligne du tableau sans relancer la grille.
