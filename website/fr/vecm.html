VECM / Johansen

Modèles vectoriels à correction d’erreur et tests de rang de Johansen.

  • Régression reduced-rank (Johansen / Lütkepohl)
  • Huit spécifications déterministes, dont les variantes JHJ
  • P-values et valeurs critiques MacKinnon–Haug–Michelis (1999)
  • IRF, FEVD, Granger, JB, whiteness, diagnostics et prévisions natifs

README : makystats/vecm/README.md · Guide technique : DOCUMENTATION.md

Paramètres (API makystats — pas statsmodels)

ParamètreValeursRôle
test_case'1'…'5'Spécification du test de rang
det_case'1'…'5b'Spécification de l’estimation (défaut '3a')
k_ar_diffint ≥ 0Retards en différences (= ordre VAR en niveau − 1)
coint_rankintRang de cointégration r

3a/4a/5a = termes duals JHJ ; 3b/4b/5b = contreparties classiques.

Workflow minimal

order = select_var_order(data, maxlags=4, criterion="bic")
k_ar_diff = order.best - 1
summarize_johansen(data, k_ar_diff=k_ar_diff, signif=0.05)
rank = select_coint_rank(data, k_ar_diff=k_ar_diff, test_case="3")
model = VECM(data, k_ar_diff=k_ar_diff, coint_rank=max(rank.rank, 1),
             det_case="3a").fit()
model.summary()
print(model.forecast(steps=5, conf_int=True, method="bootstrap", sim_reps=1000))
model.irf(10).plot()
model.plot_diagnostics()
