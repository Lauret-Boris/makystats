Installation

Depuis PyPI

pip install makystats
pip install "makystats[numba]"   # optionnel : filtre GARCH plus rapide
pip install "makystats[plot]"    # optionnel : graphiques matplotlib
pip install "makystats[all]"     # numba + plot

Prérequis

  • Python ≥ 3.9 (testé jusqu’à 3.14)
  • numpy, pandas, scipy, statsmodels

Vérification

python -c "import makystats; print(makystats.__version__)"

Depuis les sources

git clone https://github.com/Lauret-Boris/makystats.git
cd makystats
pip install -e ".[numba,plot,test]"
