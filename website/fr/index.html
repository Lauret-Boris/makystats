makystats

Boîte à outils économétrique pour Python — ARMA, ARMA–GARCH (MV), VAR, VECM / Johansen et ARDL (test aux bornes, ECM).

v0.1.3 Python ≥ 3.9 MIT pip install makystats

Modules

ARMA

AR / ARMA / ARIMA / SARIMA homoscédastiques. Sélection d’ordres, diagnostics, prévisions en niveau avec conservation de l’index.

ARMA–GARCH

MV jointe : moyenne + GARCH / GJR / EGARCH / APARCH / FIGARCH. VaR, ES, saisonnalité.

VAR

VAR OLS natif, IRF, FEVD, causalité de Granger, sélection d’ordres.

VECM

Cointégration de Johansen, p-values MHM, huit cas déterministes, prévisions.

ARDL

Test aux bornes, UECM, ECM restreint, coefficients de long terme, CUSUM.

Installation

pip install makystats
pip install "makystats[numba]"
pip install "makystats[plot]"
