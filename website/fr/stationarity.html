Tests de stationnarité / racines unitaires

Implémentations natives dans makystats.stationarity_test (distinct des modules d’estimation). Tableaux OLS inspectables, comparaisons multi-spécifications et stratégie ADF séquentielle.

Guide : makystats/stationarity_test/README.md

Import

from makystats import (
    adf, adf_sequential,
    kpss, pp, dfgls, za,
    engle_granger, unit_root_summary,
)

Exemples rapides

print(adf(y, regression="ct").summary())
print(adf(y, regression="ct").ols.summary())

seq = adf_sequential(y)
print(seq.summary())
seq.plot()

print(unit_root_summary(y))

Paramètres principaux

FonctionArguments clés
adf(y, …) regression = n / c / ct · maxlag · autolag = AIC / BIC / None (IC de retards sur un échantillon commun)
adf_sequential(y, …) maxlag · autolag · alpha (défaut 0.05) — retard choisi sur le modèle 3, puis chemin 3→2→1 avec tests Φ
kpss(y, …) regression = c / ct · nlags = auto ou int
pp(y, …) regression = n / c / ct · lags = auto ou int
dfgls(y, …) regression = c / ct · maxlag · autolag = AIC / BIC / MAIC
za(y, …) regression = c / t / ct (type de rupture) · trim (défaut 0.15) · maxlag · autolag · lag_policy = per_break / global

Résultats : .summary(), et le cas échéant .ols / .regression.summary(). ADF séquentiel : seq.adf_model(3), seq.plot(). Helpers : kpss_compare, pp_compare, dfgls_compare, za_compare, unit_root_summary.
