VAR

Vector Autoregression estimé par OLS (natif). Sélection d’ordres, IRF, FEVD, prévisions multi-pas et diagnostics de résidus.

Import

from makystats import VAR, select_var_order, fit_from_var_order_table

Sélection d’ordres — select_var_order

res = select_var_order(data, maxlags=8, minlags=1, det="c", criterion="bic",
                       common_sample=True, return_best=True)
ParamètreDescription
dataSérie multivariée (T × k).
maxlags, minlagsPlage de retards.
det'n', 'c', 'ct', 'ctt'.
criterion'aic', 'bic', 'hqic', 'fpe'.
common_samplebool, défaut True — même échantillon pour tous les ordres (IC comparables).
return_bestRetourne aussi le modèle ajusté pour le retard choisi.
