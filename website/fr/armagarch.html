ARMA–GARCH

Maximum de vraisemblance jointe d’une moyenne linéaire (ARMA / ARX / HAR / …) et d’une variance conditionnelle (GARCH, GJR, EGARCH, APARCH, FIGARCH) sous innovations normale, Student-t, skew-t ou GED.

README : makystats/armagarch/README.md · Guide technique : DOCUMENTATION.md

Démarrage rapide

from makystats import arma_garch, select_order
res = arma_garch(y, mean="AR", ar=1, ma=1, vol="GARCH", trend="c").fit()
print(res.coef_table)
print(res.forecast(h=5))
res.plot_diagnostics(lags=20)
tab = select_order(ylog, p_range=range(0, 3), q_range=range(0, 2),
                   r_range=[1], s_range=[1], d=1,
                   seasonal_order=(0, 1, 1, 12), criterion="aic")

API en bref

ArgumentRôle
meanConstant, Zero, AR, ARX, ARMAX, HAR, HARX, LS
in_meanGARCH-M : None / sigma / var / log (coef archm)
trendn / c / t / ct
volGARCH, ARCH, GJR/TARCH, EGARCH, APARCH, FIGARCH
distnormal, t, skewt, ged
ar / maOrdres ou listes de lags (ARMA creux). Coefficients libres (pas de borne ±0,99)
r / sOrdres ARCH / GARCH (r=s=0 → variance constante)
powerPuissance APARCH δ (défaut 2.0)
threshold_orderOrdre d’asymétrie GJR/TARCH (défaut = r)
dDifférences régulières 0, 1 ou 2
seasonal_order(P, D, Q, s) saisonnalité additive de la moyenne
nonneg_varTrue → impose α, β ≥ 0 (optionnel ; défaut libre)
stationary_varTrue → impose persistance de variance < 1 (GARCH : α+β ; GJR : α+γ/2+β)
egarch_formcentered (défaut) ou raw pour ω EGARCH
cov_typeopg (défaut) ou SE basés sur la Hessienne
backcastλ du backcast exponentiel de variance (défaut 0.7)
centerCentrer y pendant l’optimisation (défaut True)

Polynômes AR/MA alignés sur le filtre : Φ(z)=1−Σφzk, Θ(z)=1+Σθzk. Prévisions de variance multi-pas : moments sous la densité estimée (normale / t / skew-t / GED).
