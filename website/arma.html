ARMA / ARIMA / SARIMA

Homoskedastic mean models (constant variance). Same mean-API spirit as arma_garch, without GARCH dynamics.

Quick start

from makystats import arma, arima, sarima, select_arma_order

# ARIMA(1,1,1) with constant
res = arma(y, mean="ARMA", ar=1, ma=1, d=1, trend="c").fit()
print(res.summary())

# Sparse / “gapped” ARMA
res = arma(y, mean="ARMA", ar=[4], ma=1, d=1, trend="c").fit()

# SARIMA with additive seasonal lags
res = arma(y, mean="ARMA", ar=0, ma=1, d=1,
           seasonal_order=(1, 1, 1, 12), trend="c").fit()

# Order selection (optional seasonal_order)
tab = select_arma_order(y, max_ar=3, max_ma=3, d=1, trend="c", ic="bic")

Main parameters

ParameterDescription
mean"AR", "ARMA", "ARX", "HAR", …
ar, maInteger order or list of lags (sparse ARMA)
dNon-seasonal difference order
seasonal_order(P, D, Q, s) additive seasonal pattern
trend"n" / "c" / "t" / "ct"

Results (statsmodels-style)

  • params, bse, tvalues, pvalues — named Series
  • cov_params(), conf_int()
  • arroots, maroots
  • test_serial_correlation, test_heteroskedasticity, test_normality
  • residuals, fittedvalues, fitted_values_level — original index preserved
  • forecast(steps=…), aic / bic / hqic / llf
