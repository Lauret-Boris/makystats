makystats

Econometrics toolkit for Python — ARMA, ARMA–GARCH (MLE), VAR, VECM / Johansen, ARDL (bounds test, ECM), and unit-root / stationarity tests.

v0.1.8 Python ≥ 3.9 MIT pip install makystats

Modules

ARMA

Homoskedastic AR / ARMA / ARIMA (optional exact Kalman likelihood) / SARIMA. Exact multi-step forecast SE (MA∞ ψ-weights), order selection, diagnostics.

ARMA–GARCH

Joint MLE: mean + GARCH / GJR / EGARCH / APARCH / FIGARCH. Domain repair, VaR & ES, seasonal mean.

VAR

Native OLS VAR, IRF, FEVD, Granger causality, order selection.

VECM

Johansen cointegration, MHM p-values, eight deterministic cases, forecasts.

ARDL

Bounds test, UECM, restricted ECM, common-sample order selection, long-run coefficients, CUSUM.

Stationarity

ADF, sequential ADF, KPSS, Phillips–Perron, DF-GLS, Zivot–Andrews, Engle–Granger.

Installation

pip install makystats
pip install "makystats[numba]"
pip install "makystats[plot]"
