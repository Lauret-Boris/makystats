ADF (Augmented Dickey–Fuller)

Native ADF unit-root test with MacKinnon p-values. Lag selection by AIC/BIC is done on a common sample so information criteria are comparable.

Import

from makystats import adf

Quick start

res = adf(y, regression="ct", maxlag=None, autolag="AIC")
print(res.summary())
print(res.statistic, res.pvalue, res.lags)
print(res.ols.summary())   # ADF regression table

Parameters

ParameterTypeDescription
yarray_like / SeriesSeries to test. Time index is kept for plots when available.
maxlagint or NoneMaximum augmentation lag. Default: rule of thumb from sample size.
regressionstr, default 'c' Deterministics in the ADF regression: 'n' none, 'c' constant, 'ct' constant + trend, 'ctt' constant + trend + quadratic.
autolagstr or None, default 'AIC' 'AIC', 'BIC', or None/'NONE' (use fixed maxlag). Candidates are compared on a common estimation sample.
