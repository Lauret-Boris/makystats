Phillips–Perron

Unit-root test with non-parametric (Newey–West) correction of the Dickey–Fuller regression. Reports Z(τ) and Z(ρ).

Import

from makystats import pp
# or: phillips_perron, pp_compare

Quick start

res = pp(y, regression="c", lags="auto")
print(res.summary())
print(res.statistic, res.pvalue)

Parameters

ParameterTypeDescription
yarray_like / SeriesSeries to test.
regressionstr, default 'c''n', 'c', or 'ct'.
lagsstr or int, default 'auto'Newey–West lag for the long-run variance correction.
