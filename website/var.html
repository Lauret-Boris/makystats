VAR

Vector Autoregression estimated by OLS (native). Order selection, IRF, FEVD, multi-step forecasts and residual diagnostics.

README: makystats/var_model/README.md

Import

from makystats import VAR, select_var_order, fit_from_var_order_table

Order selection — select_var_order

res = select_var_order(data, maxlags=8, minlags=1, det="c", criterion="bic",
                       common_sample=True, return_best=True)
s = res.summary()  # str
print(s)
best = res.best_model   # if return_best=True
ParameterTypeDescription
dataDataFrame / ndarrayMultivariate series (T × k).
maxlags, minlagsintLag search range (inclusive).
detstr, default 'c'Deterministics: 'n' none, 'c' constant, 'ct' constant + trend, 'ctt' + quadratic.
criterionstr, default 'bic''aic', 'bic', 'hqic', 'fpe'.
common_samplebool, default TrueEstimate all lag orders on the same effective sample so ICs are comparable.
return_bestboolAlso return a fitted model for the selected lag.
columnssequence or NoneVariable names when data is an ndarray.

fit_from_var_order_table(...) refits a chosen lag without re-running the grid.

Estimation — VAR / VARModel

model = VAR(data, lags=2, det="c")
res = model.fit()
s = res.summary()  # str
print(s)
print(res.forecast(steps=8))
irf = res.irf(10); irf.plot()
ParameterDescription
lagsVAR order p
detDeterministics (n/c/ct/ctt)
columnsNames for ndarray input
