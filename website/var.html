VAR

Native ordinary-least-squares vector autoregression with the usual post-estimation toolkit.

from makystats import var_model, select_var_order

res = var_model(data, lags=2).fit()
print(res.summary())

# Order selection
tab = select_var_order(data, maxlags=8, ic="bic")

# IRF / FEVD / Granger
irf = res.irf(periods=12)
fevd = res.fevd(periods=12)

Features

  • Deterministic terms (constant / trend) consistent with the package API
  • Impulse responses and forecast-error variance decomposition
  • Granger causality tests
  • Lag-order selection via information criteria

Guide: makystats/var_model/README.md.
