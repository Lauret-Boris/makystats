ARDL

Autoregressive Distributed Lag models: levels ARDL, UECM, PSS bounds test, ECM representation, long-run coefficients and multi-step forecasts.

README: makystats/ardl/README.md · Guide: DOCUMENTATION.md · Reference: statsmodels ARDL

Import

from makystats import select_ardl_order, fit_from_ardl_order_table
# or: from makystats.ardl import select_ardl_order

Order selection — select_ardl_order

tab, best = select_ardl_order(
    y, x,
    maxlag=4, maxorder=4,
    case=3,           # PSS deterministic case 1–5
    ic="bic",
    common_sample=True,  # default: all candidates on the same sample
    refit_best=True,
)
ParameterTypeDescription
yarray_like / SeriesDependent variable (levels).
xDataFrame / ndarrayExogenous regressors (levels). Column names become coefficient labels.
maxlagint, default 4Maximum lag of y (AR part).
maxorderint, dict or list, default 4Maximum lag of each x column. A dict maps column → max lag; a list is per-column in order.
caseint 1–5, default 3 PSS deterministic case: 1 no intercept/trend; 2 restricted intercept; 3 unrestricted intercept; 4 restricted trend; 5 unrestricted trend.
trendstr or NoneOptional override of deterministics (otherwise implied by case).
fixedoptionalRegressors forced into every candidate (not searched over lags).
ic'aic'|'bic'|'hqic', default 'bic'Information criterion for ranking.
common_samplebool, default True If True, every candidate is estimated on the same effective sample (start = max(maxlag, max maxorder)) so AIC/BIC/HQIC are comparable. If False, each order uses its natural sample (old behaviour).
refit_bestbool, default TrueAfter selection, refit the winning order on its natural sample (full length for that order).
max_modelsint, default 5000Safety cap on the number of candidates evaluated.
verboseboolProgress messages.

fit_from_ardl_order_table(tab, rank=1) re-estimates a row of the order table without re-running the grid (aligned with return_best).

Fitted model — useful attributes

Attribute / methodContent
summary()Coefficient table, diagnostics
bounds_test / F, tPSS bounds statistics (F = Wald/q)
long_run, long_run_levelsLong-run coefficients (CE scale / levels)
ecm / restrict_ecmError-correction form (Bardsen when drop empty)
forecast / forecast_ecmLevel or difference forecasts
# Bounds + long-run
s = best.summary()  # str
print(s)
print(best.long_run)

# Forecast levels
print(best.forecast(steps=8, conf_int=True))

Notes

  • common_sample=True (default since 0.1.9) is the recommended setting for fair IC comparison across lag orders.
  • Cases 3–5 control the intercept/trend placement in the UECM / ECM consistently with the PSS tables.
  • For full UECM/ECM dating and restricted ECM details, see the package README.
