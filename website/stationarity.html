Stationarity / unit-root tests

Native implementations of ADF, sequential ADF, KPSS, Phillips–Perron, DF-GLS (ERS), Zivot–Andrews and Engle–Granger. No third-party unit-root engine is required for the core statistics.

Guide: makystats/stationarity_test/README.md

Import

from makystats import (
    adf, adf_sequential,
    kpss, pp, dfgls, za,
    engle_granger, unit_root_summary,
)
# aliases: phillips_perron, df_gls, zivot_andrews_test, ers, kpss_test
