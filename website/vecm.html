VECM / Johansen

Vector Error-Correction Model and Johansen cointegration tests (trace / max-eigen), with MHM p-values and critical values.

README: makystats/vecm/README.md · Guide: DOCUMENTATION.md

Import

from makystats import VECM, select_coint_rank, JohansenTest, summarize_johansen

Rank selection — select_coint_rank

rank_res = select_coint_rank(
    data, k_ar_diff=1, test_case="3", method="trace", signif=0.05
)
print(rank_res.summary())  # rank table
print(rank_res.rank)
ParameterTypeDescription
dataDataFrame / ndarrayLevels data (T × k).
k_ar_diffint, default 1Number of lagged differences in the VECM (VAR order in levels is k_ar_diff + 1).
test_casestr '1'…'5', default '3' Deterministic case for the Johansen test (intercept/trend placement in the cointegration space and VAR).
method'trace'|'maxeig'Trace or maximum-eigenvalue statistic.
signiffloat, default 0.05Significance level for sequential rank decision.
columnssequence or NoneNames when data is an ndarray.

P-values use the MacKinnon–Haug–Michelis (MHM) response surfaces. summarize_johansen reports critical values in a compact table.

Estimation — VECM / VECMModel

mod = VECM(data, k_ar_diff=1, coint_rank=1, det_case="3a")
res = mod.fit()
s = res.summary()  # str
print(s)
print(res.results_frame(level=False).head())  # ΔY / fitted / resid; level=True for levels
print(res.forecast(steps=8))
ParameterTypeDescription
k_ar_diffintLagged differences in the VECM.
coint_rankintCointegration rank r.
det_casestr Deterministic specification for estimation: '1', '2', '3a', '3b', '4a', '4b', '5a', '5b' (intercept/trend inside or outside the cointegrating relation).
columnssequence or NoneVariable names for ndarray input.

Note: makystats uses test_case / det_case (not statsmodels’ det_order / deterministic strings).
