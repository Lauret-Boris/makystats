Installation

From PyPI

pip install makystats
pip install "makystats[numba]"   # optional: faster GARCH filter
pip install "makystats[plot]"    # optional: matplotlib plots
pip install "makystats[all]"     # numba + plot

Requirements

  • Python ≥ 3.9 (tested through 3.14)
  • numpy, pandas, scipy, statsmodels

Check

python -c "import makystats; print(makystats.__version__)"

From source

git clone https://github.com/Lauret-Boris/makystats.git
cd makystats
pip install -e ".[numba,plot,test]"
Published package version on this documentation site: 0.1.2.
