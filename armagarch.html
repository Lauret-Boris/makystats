ARMA–GARCH

Joint MLE of a linear mean (ARMA / ARX / HAR / …) and conditional variance (GARCH, GJR, EGARCH, APARCH, FIGARCH) under normal, Student-t, skew-t or GED innovations.

README: makystats/armagarch/README.md · Guide: DOCUMENTATION.md

Import

from makystats import arma_garch, select_order

Recommended presets

Two useful ways to set the same API, depending on whether you want unrestricted coefficients or constrained variance parameters (closer to packages such as arch / constrained solvers).

GoalTypical settingsEffect
Unrestricted ML (default) nonneg_var=False, domain_repair=True, n_starts=1, cov_type='opg' α, β free (may be negative if σ² stays positive). If the free optimum leaves the classical domain, one constrained retry may replace it. Single variance start (β≈0.85).
Fully free optimum domain_repair=False, nonneg_var=False Never replace the unrestricted solution; no domain UserWarning.
Constrained variance (α, β ≥ 0) nonneg_var=True, optional stationary_var=True α, β forced ≥ 0 via exp map; optional persistence < 1. Closer to constrained GARCH solvers (e.g. arch).
Robust SE cov_type='qml' or 'robust' Bollerslev–Wooldridge sandwich (QMLE). Default remains OPG.
Less start-dependent n_starts=4 (or more) Several (α, β) starts; each is polished and domain-repaired; best final LL kept. Cost ≈ linear in n_starts.
statsmodels-like mean trend='c'|'ct'|'n', d=, seasonal_order= Deterministics and integration follow the same coding spirit as ARIMA/SARIMAX; variance is still makystats GARCH. 
# Unrestricted (default)
res = arma_garch(y, mean="AR", ar=1, ma=1, vol="GARCH").fit()

# Constrained variance (α,β ≥ 0), sandwich SE
res = arma_garch(y, vol="GARCH", nonneg_var=True, stationary_var=True,
                 cov_type="qml").fit()

# Multi-start when small samples / high persistence matter
res = arma_garch(y, vol="GARCH", n_starts=4).fit()
print(res.optimization["best_start_idx"], res.optimization["selection"])

Domain repair

When nonneg_var=False, unrestricted MLE can exit with α < 0, β < 0, or (GJR/TARCH) α+γ < 0. With domain_repair=True (default), fit() re-optimises once under non-negativity. For GJR, δ = α+γ ≥ 0 is enforced in the constrained map. Acceptance: domain OK, finite NLL, at most 50 LL units worse than the free optimum. Flags: domain_retry, domain_retry_accepted, unconstrained_ll. Disable with domain_repair=False.

When a constrained retry is accepted, res.converged is re-assessed on the repaired solution (practical flag; free-solution polish_delta is not used), so accepted repairs are not falsely marked failed.

Multi-start (n_starts)

Default n_starts=1 uses a single variance start (β≈0.85, α≈0.05 for GARCH). With n_starts>1, several (α, β) pairs are tried (including low-β starts). Each start is fully polished and domain-repaired; the winner is the best final log-likelihood (selection='final_loglik_after_polish_and_repair'). This avoids ranking on raw BFGS NLL before repair.

FIGARCH

Full truncation window (1000) with backcast for pre-sample lags. d clamped to (0.001, 0.999). Multi-step variance paths may still differ from other packages by a few percent at long horizons (documented caveat).

Order selection

tab, best = select_order(
    y, p_range=range(0, 3), q_range=range(0, 2),
    r_range=[1], s_range=[1], criterion="bic",
    return_best=True,
    # optional: domain_repair=, nonneg_var=, n_starts=, start=
)

start=None (default): grid uses 'fast'; return_best is refit with 'precise'. An explicit start= is applied to both.
